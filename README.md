# QuizMaster 🧠

A web-based quiz application developed as a college project using React.js and Vite.

## 📌 Project Overview

QuizMaster is an interactive quiz application that allows users to participate in quizzes, answer questions, navigate through different quiz screens, and view their results.

The project demonstrates the practical implementation of modern frontend development concepts using React.js, including reusable components, routing, custom hooks, data management, and responsive styling.

## 🎯 Objectives

- To develop an interactive and user-friendly quiz application.
- To implement a component-based architecture using React.js.
- To implement navigation between different application screens.
- To manage quiz data and user interactions efficiently.
- To use React hooks for application logic and state management.
- To create a responsive and visually appealing user interface.
- To gain practical experience in frontend web development.

## ✨ Features

- 🧠 Interactive quiz interface
- ❓ Multiple-choice questions
- 📝 Question navigation
- 📊 Quiz score and results
- 🔄 Dynamic quiz flow
- 🧩 Reusable React components
- 🧭 Client-side routing
- 🪝 Custom React hooks
- 💾 Utility functions for application data/storage
- 📱 Responsive user interface

## 🛠️ Technologies Used

- **React.js** – Frontend development
- **Vite** – Development and build tool
- **JavaScript (JSX)** – Programming language
- **CSS** – User interface styling
- **React Router** – Application navigation
- **npm** – Package management
- **ESLint** – Code quality and linting
